# Ռուլետկա · Խաղարկություն «Մինչև վերջ»

Розыгрыш призов на конференции: рулетка-спидометр в стиле LED-экрана (асфальт, оранжевое свечение, дороги).
Статический сайт без сборки: `index.html`, `style.css`, `app.js`, `assets/`.

## Как пользоваться

- **ՊՏՏԵԼ** (или `Space` / `Enter`) — запустить. Стрелка «газует» по шкале и останавливается на выигравшем номере.
- Карточка победителя закрывается кнопкой **ՇԱՐՈՒՆԱԿԵԼ**, `Space`, `Enter` или `Esc`.
- **Настройки** — шестерёнка справа вверху или клавиша `S`:
  - количество участников (1–100 000), первый номер;
  - название приза: показывается под заголовком и на карточке победителя;
  - исключить номера: `7, 13, 20-25`;
  - не повторять выпавшие номера (включено по умолчанию);
  - длительность прокрутки 4–16 секунд и звук;
  - список всех победителей, «отменить последний», «очистить историю».
- `F` — полный экран. Кнопки справа вверху прячутся, когда мышь не двигается.
- Ссылка с параметрами: `/?n=500` задаёт 500 участников, `/?n=480&from=1` задаёт и первый номер.

## Честность

Победитель выбирается один раз в момент нажатия через `crypto.getRandomValues`,
равномерно среди номеров, которые ещё в игре. Метод без смещения по модулю.
Движение стрелки — только анимация, которая подводит к этому номеру.

Настройки и история хранятся в браузере (`localStorage`), поэтому после перезагрузки страницы они не теряются.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173.
